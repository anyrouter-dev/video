anyr – point any coding agent at AnyRouter

Start
  $ curl -fsSL https://anyrouter.dev/setup.sh | bash
  $ anyr auth login
  $ anyr claude                 # default model: anyrouter/auto

Swap the model, keep the agent
  $ anyr claude --model z-ai/glm-4.7-flash
  $ anyr claude --yolo --model anyrouter/auto[1m]
  $ anyr claude --model anyrouter/free[1m]
  $ anyr claude --model anyrouter/auto[500k]
  $ anyr claude --model auto --effort high

Same key, other agents
  $ anyr codex --model anthropic/claude-sonnet-4.6
  $ anyr grok --effort high

Structured decisions (not chat)
  $ anyr decision --model typesafe/jev --state 'A payout is failing' --questions '{"urgent":{"type":"noul"}}'

Dashboard from the terminal
  $ anyr api credits
  $ anyr api keys create ci-bot

Preflight: bare anyr confirms account / model / agent, then launches.
anyr help commands for the full map.
